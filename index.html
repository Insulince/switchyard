Everything set up here is written to config.json. That file is the source of truth — editing it by hand and restarting works exactly the same way, and this form is only a convenience.

Reset all statistics?

Clears every counter, average and share-of-work figure, and restarts the clock they are measured from.

Nothing disconnects. Rig sessions, gateway sessions, difficulty and the rotation schedule all carry on untouched — only the measurements go.

The fairness band will widen again afterwards, because it genuinely will know less. This cannot be undone.

Rotate now?

Moves every rig to its next pool immediately, ignoring the dwell floor and the block that would normally trigger it.

Each rig reconnects once. Rotations forced by hand are counted like any other, so doing this often will skew the share-of-work figures.
